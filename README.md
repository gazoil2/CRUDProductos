# BOX S.A.

## Consignas

Diseñar y desarrollar mediante MySQL Workbench el Modelo Relacional de la Base de Datos para la empresa BOX
S.A. en función del relevamiento realizado.

Desarrollar un CRUD en Python con Flask con el objetivo de administrar la
generación de Ordenes de Venta (OV) para la empresa Box SA.
Se deberá cumplir las siguientes consignas:

1. Permitir seleccionar un Cliente existente.
2. Mostrar o validar los Productos a vender según el Cliente seleccionado.
3. Permitir la carga de N cantidad de productos diferentes para la venta.
4. Considerar en la carga de los productos el stock de sus componentes.
5. Generar la reserva de los componentes según Receta de Materiales.
6. Grabar la OV en las tablas correspondientes del schema.
7. Mostrar el número de la OV.
